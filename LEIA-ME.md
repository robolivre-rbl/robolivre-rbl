# RoboLivre — versão HTML estática

A aplicação Standalone/SPA foi convertida para páginas HTML independentes.

## Páginas

- `index.html`
- `sobre.html`
- `historia.html`
- `projetos.html`
- `kits.html`
- `contato.html`
- `redes.html`
- `404.html`

## Arquivos compartilhados

- `css/styles.css` — estilos
- `js/site.js` — menu, tema, filtros, contato, animações e simulador BuzzLine
- `assets/` — imagens e vetores
- `referencia/` — código `.ino`

A navegação não usa mais `#/rota`: cada página possui seu próprio arquivo HTML.
